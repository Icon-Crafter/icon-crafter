# Testing & benchmarks

## Layers

| Layer | Command | What it must prove |
|---|---|---|
| Engine crates | `cargo test -p dp-geom -p dp-model -p dp-text -p dp-layout -p dp-render -p dp-io -p dp-persist -p dp-collab -p dp-prototype -p dp-devmode -p dp-plugins -p dp-ai` | pure logic, serialization round-trips, migrations, rendering golden images, geometry invariants |
| Workspace | `cargo test --workspace --exclude iconcrafter-desktop --exclude iconcrafter-server` | everything above in one run |
| Desktop shell | `cargo check -p iconcrafter-desktop` + manual launch | IPC compiles; app launches, canvas renders, export files open |
| UI | `pnpm --dir apps/ui test` (vitest) and `pnpm --dir apps/ui build` | state/commands/utilities; production bundle builds |
| Backend unit | `cargo test -p iconcrafter-server` | validators, permission matrix, token hashing, repository in-memory tests |
| Backend integration | `cargo test -p iconcrafter-server -- --ignored` with `DATABASE_URL` set | real Postgres migrations + route tests (requires Docker or a local PG) |
| Formatting | `cargo fmt --all -- --check` | style |
| Lints | `cargo clippy --workspace --all-targets -- -D warnings` | no warnings in owned code |

CI (`.github/workflows/ci.yml`, planned) runs: fmt, clippy, workspace tests, UI build,
and (on Linux runner) backend tests with a Postgres service container.

## Fixtures

  (planned) for performance tests.

  tolerance-based comparator (max channel delta + changed-pixel ratio), never exact bytes.

## Performance benchmarks

Targets are stated in `docs/ARCHITECTURE.md`; measured numbers will be committed to
`docs/PERFORMANCE.md` with host specs and the exact command. Benchmarks are plain
`cargo run --release -p <crate> --example bench_*` binaries (no nightly-only harness):
scene build + raster for a 10k-node document, hit testing, layout of nested auto-layout
trees, text shaping of a 1000-paragraph document, save/load round-trip, undo replay.
Numbers are reported honestly, including regressions.

## Manual verification checklist (vertical slice)

Run `pnpm --dir apps/ui build` then `cargo run -p iconcrafter-desktop` (or `pnpm tauri dev`):

1. App launches with app icon and dark editor chrome; no console errors.
2. Draw a rectangle, ellipse, polygon; move/resize/rotate; multi-select and marquee.
3. Type text on canvas; edit it; toggle bold via inspector.
4. Undo/redo all of the above; verify state matches after 20 random ops.
5. Zoom/pan (wheel, space-drag, fit, zoom to selection); rulers update.
6. Save to `.icraft`, close, reopen: every property, layer order and page intact.
7. Export PNG at 1x/2x/3x and SVG; open both outside the app and visually compare.
8. Kill the process mid-edit; relaunch: autosave recovery prompt restores the document.
9. Keyboard-only pass: tab through panels, command palette opens, focus ring visible.
10. Very large document (10k nodes): pan/drag remains usable; report frame timings.

Record pass/fail and timings in `DEVELOPMENT-LOG.md` for each release candidate.

## Session 4 verification (prototype runtime + lint gate)

```pwsh
# One engine suite, all default-members (excludes Tauri/server heavy trees):
cargo test -p dp-geom -p dp-model -p dp-text -p dp-layout -p dp-render `
  -p dp-io -p dp-persist -p dp-editor --no-default-features
# Expected: 44 + 65 + 13 + 12 + (6 unit + 11 integration) + 9 + 13 + 19 = 192 passed.

# Prototype runtime + expression language:

cargo clippy -p dp-prototype --all-targets -- -D warnings   # clean

# Strict lint gate for all engine crates:
cargo clippy -p dp-geom -p dp-model -p dp-text -p dp-layout -p dp-render `
  -p dp-io -p dp-persist -p dp-editor -p dp-prototype `
  --no-default-features --all-targets -- -D warnings
# Expected: exit 0.
```

Notes:

* `dp-prototype` is a pure runtime: it executes `dp-model` interactions without mutating the
  document; tests cover navigation history, overlay stacking, transitions/timers, key triggers,
  variables and flow validation.
* Disk: after the incident the profile is `debug = 0` / `incremental = false`. Full engine test
  builds use roughly 3-4 GB; do not run desktop + backend + engine builds simultaneously.
